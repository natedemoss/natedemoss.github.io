This is the first post on this blog. The body is set in Source Serif 4 at a comfortable measure of about 680 pixels — wide enough to breathe, narrow enough to read.

## A section heading

Paragraphs flow naturally. Inline code like `np.einsum("ij,jk->ik", A, B)` sits inside the line. Block code looks like:

```python
def softmax(x):
    e = np.exp(x - x.max(axis=-1, keepdims=True))
    return e / e.sum(axis=-1, keepdims=True)
```
